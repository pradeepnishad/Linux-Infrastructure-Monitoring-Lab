# Node Exporter — Linux Host Metrics

## Overview

Prometheus Node Exporter exposes operating-system and hardware-related metrics from Linux servers through an HTTP endpoint.

Prometheus scrapes these metrics and stores them as time-series data. Grafana then visualizes selected metrics.

## Architecture

```text
Linux operating system
        |
        v
  Node Exporter
     :9100
        |
        | HTTP metrics endpoint
        v
   Prometheus
     :9090
```

## Service Management

Check service status:

```bash
sudo systemctl status prometheus-node-exporter --no-pager
```

Check whether the service is running:

```bash
systemctl is-active prometheus-node-exporter
```

Check whether it is enabled at startup:

```bash
systemctl is-enabled prometheus-node-exporter
```

Restart the service:

```bash
sudo systemctl restart prometheus-node-exporter
```

The lab also tested stopping and starting the service individually. The final active-state check returned `active`.

## Check the Listening Port

```bash
sudo ss -lntp | grep ':9100'
```

## Test the Metrics Endpoint

From the machine running Node Exporter:

```bash
curl http://127.0.0.1:9100/metrics
```

From the Prometheus server, use the target's private IP:

```bash
curl --connect-timeout 5 http://10.10.10.11:9100/metrics
```

Change the IP to match the actual target.

## Important Metrics

| Metric | Meaning |
|---|---|
| `node_cpu_seconds_total` | Cumulative CPU time by mode |
| `node_memory_MemTotal_bytes` | Total memory |
| `node_memory_MemAvailable_bytes` | Estimated memory available |
| `node_filesystem_size_bytes` | Filesystem capacity |
| `node_filesystem_avail_bytes` | Available filesystem space |
| `node_network_receive_bytes_total` | Cumulative received network bytes |
| `node_network_transmit_bytes_total` | Cumulative transmitted network bytes |

## Prometheus Target Health

The `up` metric reports whether Prometheus successfully scraped a target:

- `1` means the most recent scrape succeeded.
- `0` means the most recent scrape failed.

A running Node Exporter process does not guarantee that Prometheus can reach it. Network access and Prometheus configuration must also be correct.

## Troubleshooting

If the target is down:

1. Check the service state.
2. Check port `9100`.
3. Test `/metrics` locally.
4. Test `/metrics` from the Prometheus server.
5. Verify the IP address, routing and firewall.
6. Recheck the target status in Prometheus.

## Conclusion

Node Exporter provides the host metrics used by the monitoring dashboards and alert rules in this project.
